## Brand & Style

This design system embodies high-octane cyberpunk arcade futurism tailored for an AI prompt-to-game development platform. The aesthetic bridges the raw adrenaline of vintage coin-op cabinets with the precision of next-generation developer tooling.

### Personality & Core Attributes
- **Electric & Immersive:** Dark obsidian canvas electrified by sharp neon gradients, evoking midnight arcade lounges and synthesis chambers.
- **Architectural & Rigorous:** Precise grid mechanics, diagnostic HUD readouts, and structured modules ensure heavy AI workflows feel controlled rather than chaotic.
- **Kinetic & Rewarding:** Generative states, compilation progress, and real-time generation pulses provide tactile visual feedback through layered luminescence and glossy borders.

### Design Style: Neo-Arcade Glass & HUD Minimal
A deliberate fusion of Cyberpunk Glassmorphism and HUD (Heads-Up Display) utility. The system utilizes rich, light-absorbing dark values overlaid with sharp, 1px specular edges, subtle phosphor luminescence, and monospaced technical telemetry.

## Colors

The palette is engineered around an ultra-deep void base that allows hyper-saturated luminous accents to command visual priority without eye strain.

### Palette Architecture
- **Primary (`#06b6d4` Electric Cyan):** Core action state, active node synthesis, high-frequency energy, compilation indicators.
- **Secondary (`#6366f1` Neon Indigo):** Structural navigation, secondary workflows, deep pipeline state vectors, and container rims.
- **Tertiary (`#ec4899` Neon Magenta / Hot Pink):** Critical triggers, game engine warnings, generative anomalies, and high-impact arcade rewards.
- **Neutral (`#0a0c10` Obsidian Void):** Pure dark substrate layered into `slate-950` (`#090d16`) and `zinc-900` (`#12151f`) for container tiers.

### Functional Accents
- **System Success / Online:** `#10b981` (Emerald Phosphor)
- **Warning / Pipeline Throttle:** `#f59e0b` (Amber CRT)
- **Terminal Text / Default High-Contrast:** `#f1f5f9` (White/Silver Luminescence)
- **Terminal Text Muted:** `#64748b` (Sub-circuit Slate)

## Typography

The typographic hierarchy implements three specialized typefaces:
- **Headlines (`Space Grotesk`):** Provides a sharp, angular, retro-futuristic mechanical edge for prominent modules and showcase tiles.
- **Body & Interactive Content (`Outfit`):** Balances geometric clarity with effortless readability during continuous narrative and prompt authoring.
- **Labels, Telemetry, Prompts, & Code (`Space Mono`):** Grounds game parameters, token usage, seed indices, and syntax outputs in authentic diagnostic arcade terminal cadence. Uppercase transformations with elevated letter-spacing are applied to all status and metadata tags.

## Layout & Spacing

The viewport implements a responsive 12-column fluid grid on desktop (scaling down to 8 columns on tablet and 4 columns on mobile) framed within edge HUD margins.

### Grid & Density Dynamics
- **Workspace Density:** High-density, compact layouts inside the game generation console; modular docking panes maintain exact `space-md` gaps.
- **Showcase Arcade Viewports:** Broad margins (`margin`) with expansive `space-xl` separations to allow interactive game viewports and rendered canvas assets room to breathe.
- **Responsive Adaptations:**
  - **Desktop (>= 1280px):** 12 columns, 24px gutter, full HUD sidebars, simultaneous node tree and viewport playback.
  - **Tablet (768px - 1279px):** 8 columns, 16px gutter, collapsible parameter drawers.
  - **Mobile (< 768px):** 4 columns, 12px gutter, bottom-sheet prompt interfaces with full-bleed canvas playback cards.

## Elevation & Depth

Visual hierarchy uses tinted specular borders, background blurs, and neon phosphor bloom rather than traditional soft drop shadows.

### Layer Hierarchy
1. **Base Matrix (`#0a0c10`):** Default deep void backdrop, occasionally augmented with a faint 24px isometric dot or wireframe grid at 4% opacity.
2. **Surface Low (`#0e131f` with 70% opacity):** Structural secondary panels, docked tools, and side rails using `backdrop-filter: blur(16px)` and a subtle `rgba(255, 255, 255, 0.04)` border stroke.
3. **Surface Raised (`#151b2c` with 80% opacity):** Active prompt cards, generated asset tiles, modal overlays. Outlined with a top-lit gradient border shifting from `rgba(6, 182, 212, 0.4)` to `rgba(99, 102, 241, 0.1)`.
4. **Surface Floating / Active HUD:** Dynamic popovers, game engine viewports. Enhanced with an ambient neon bloom: `box-shadow: 0 0 24px -4px rgba(6, 182, 212, 0.25), inset 0 1px 0 rgba(255, 255, 255, 0.15)`.

## Shapes

The design system enforces a precision, low-radius shape language (`roundedness: 1`). 

### Geometric Rules
- **Base Components (Inputs, Buttons, Badges):** Fixed at `0.25rem` (4px). Clean, industrial, and sharp-cornered.
- **Containers & Glass Panels (`rounded-lg`):** Scaled to `0.5rem` (8px) to maintain a cohesive structural frame.
- **Viewport Canvas & Modal Enclosures (`rounded-xl`):** Capped at `0.75rem` (12px).
- **Specialized HUD Chamfers:** Primary game prompt cards and diagnostic header pills occasionally leverage a 45-degree micro-angled corner notch (cut-corner polygon) to reinforce the futuristic cybernetic apparatus feel.

## Components

### Buttons
- **Primary (Arcade Execute):** Gradient background from `#06b6d4` to `#6366f1`, bold text in `#0a0c10`, micro-bevel highlight on top border, outer glow `0 0 16px rgba(6, 182, 212, 0.45)`. Transform scale down (0.98) on active press with crisp mechanical response.
- **Secondary (HUD Action):** Translucent obsidian base (`rgba(14, 19, 31, 0.8)`), border 1px solid `rgba(99, 102, 241, 0.5)`, text `#22d3ee`. Hover triggers border transition to `#ec4899` with matching ambient rim lighting.
- **Ghost / Utility:** Monospaced uppercase text, neutral slate styling, cyan underline bar that expands horizontally on hover.

### Prompt Input Bar & Code Nodes
- Large obsidian glass field (`backdrop-filter: blur(20px)`), left-aligned with a blinking cyan vertical cursor indicator.
- Top-right corner displays real-time AI parameter readouts (`Space Mono`, e.g., `TOKENS: 42/512 // MODEL: NOVA-V3`).
- Border shifts on `:focus-within` to a vibrant electric cyan gradient with a subtle horizontal sweep animation.

### Chips & Glowing Status Badges
- Pill or chamfered micro-badge with a 1px border.
- Includes a 6px circular pulsating LED indicator (`box-shadow: 0 0 8px currentColor`).
- States:
  - *GENERATING:* Primary Cyan with pulsating ping animation.
  - *ONLINE / COMPILED:* Emerald `#10b981`.
  - *CRITICAL / EXCEPTION:* Magenta `#ec4899`.

### Cards & Generation Viewports
- Multi-layered card featuring a glossy top specular edge (`linear-gradient(90deg, transparent, rgba(255,255,255,0.15), transparent)`).
- Dedicated asset header displaying game metadata: engine version, seed ID, FPS readout, and quick-action arcade controls (Play, Fork, Inspect).

### Checkboxes, Radios, & Range Sliders
- Checkboxes and radios are angular with square-bracket frames. Active states trigger a solid electric cyan core with neon back-illumination.
- Sliders use a laser-thin track with a glowing magenta/cyan thumb marker and real-time numeric readouts hovering in monospaced font.

### Supplemental Platform Components
- **Arcade Telemetry Drawer:** Fixed diagnostics bar at screen bottom measuring frames per second, latency, GPU generation cycles, and active token burn rate.
- **Asset Forking Node:** Visual graph nodes connected by cyan SVG laser lines depicting procedural asset generation trees.
